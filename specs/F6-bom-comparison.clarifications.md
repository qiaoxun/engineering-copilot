## Clarifications

- Q1: 安全件/关键件清单来源（决定数量差异升"高"的规则）→ 决策：不等待质量部提供——由我方基于电池行业通用实践起草初版清单（覆盖电芯/Cell、BMS 主控与采样芯片、继电器/接触器、保险丝、高压连接器、防爆阀/泄压装置、密封件、热界面与防火隔热材料等类目，初版 ≥30 项料号规则：支持按料号前缀/名称关键词/规格描述匹配），以 DRAFT 态导入可配置的「关键件清单」（挂在项目域，作为 FR6.3.1 规则矩阵的配置输入）；由客户方质量/研发负责人（同 F5 分级规则表、F10 定版权限持有者）评审确认后置 APPROVED 方在线上生效，测试环境可整库启用；后续增改走清单维护 + 审计事件 `bomdiff.criticalpart.updated`（对齐 `<domain>.<verb>` 命名）。理由：与 F5 Q1 同构——清单是 FR6.3.1 风险规则的数据基准，复用平台 DRAFT→APPROVED 状态机避免另造审批流，且不阻塞 M3 开发启动（specs/README.md「开放问题不阻塞开发启动」约定）。（影响 FR6.3.1；关联 F10 DRAFT→APPROVED 与审计命名规范）
- Q2: 替代料列的解析约定（分隔符、多替代料、替代组）→ 决策：Phase 1 采用明确的扁平列表约定，无需等待样例数据——替代料单元格按分隔符 `、 ， ; ； | ,` 任一切分（正则 `[,;｜|、，；]`），解析后规范化为 `substitutes[]` 数组：去首尾空格、去重、忽略空片段；料号归一化为去空格后原样字符串（不做大小写折叠，料号区分大小写，与对齐键 FR6.2.1 口径一致）；单行替代料数量上限 20，超出记入 FR6.1.4 行级校验错误列表；替代组（alternate group，即"X 与 Y 互为替代、成组生效"的语义）Phase 1 **不做**，替代料一律视为无序集合，比对口径为：料号缺失但出现在对方任一行替代料集合 → 判"替代料差异"（FR6.2.3）；双方料号均存在但替代料集合不相等（无序集合比较）→ 判"替代料不一致"（FR6.2.2）；解析过程不调用 LLM（确定性规则解析，保证 AC6.2.1 可 100% 复现）。理由：PRD §19 标准字段中替代料为单列文本，主流 PLM 导出即逗号/分号/顿号分隔的扁平列表，该约定覆盖绝大多数真实数据；确定性切分使 AC6.2.1 的预置答案可比对；替代组语义需 PLM 系统数据支撑，属第二阶段直连后的场景（与 spec §6 非目标一致）。（影响 FR6.1.2、FR6.1.4、FR6.2.2、FR6.2.3、AC6.2.1）
- Q3: 同一 BOM 历史多次比对的版本留存与 diff-of-diff → 决策：Phase 1 **保留全部**历史比对运行记录（不做 diff-of-diff 功能），`GET /api/v1/bom-diff/runs?project_id=&page=&page_size=` 提供分页历史列表（含状态/总览摘要），定版（APPROVED）运行与其明细、处置记录、审计事件永久留存，DRAFT 运行可由发起人删除（删除入审计 `bomdiff.run.deleted`）；diff-of-diff（两次运行结果对比）列入 Phase 2 非目标。理由：Q3 原倾向"只保留最近 N 次"与本平台 F10 审计追溯要求冲突——处置记录与整改任务（Issue）双向链接（FR6.5.1/AC6.5.1）依赖被引用 run 长期存在，删除历史会悬挂链接、破坏 KPI（`bomdiff.start → bomdiff.confirm`）基线统计；而单次运行数据量仅千行级（500 行 BOM × 2），全量留存存储成本可忽略，"最近 N 次"的容量担忧在 Phase 1 私有化单客户部署下不成立；diff-of-diff 依赖「同一对 BOM 的多次快照」场景，Phase 1 无 PLM 直连、触发频率低，无产品支撑。（影响 FR6.4.1、FR6.5.1、AC6.5.1、§5 KPI/审计；关联 F10 审计追溯）

## Assumptions

- Q1 关键件清单 APPROVED 前的默认行为：线上运行遇未定版清单时，数量不一致一律按"中"分级（视为清单未命中），不阻塞比对任务执行（与 F5 Q1 兜底语义一致，仅约束线上生效判断）；清单启用后仅影响**新发起**的比对运行，已完成的 run 不重算（结果随 run 快照固化）。
- Q1 清单匹配粒度为料号级（支持前缀/关键词规则），Phase 1 不做物料分类主数据（分类编码体系）对接；匹配命中判定为确定性规则，不使用 LLM。
- Q2 常见导出口径已覆盖：若实际样例数据出现本约定无法解析的格式（如括号备注、含分隔符的料号），按 FR6.1.4 记入行级校验错误列表由人工修正，不静默丢弃；列映射（FR6.1.2）阶段即预览替代料解析结果供人工确认。
- Q2 替代料差异（FR6.2.3 场景）与替代料不一致（FR6.2.2 场景）统一归入 `替代料不一致` 差异类型展示，`value_a/value_b` 分别记录双方替代料集合，风险等级按 FR6.3.1 默认"中"。
- Q3 DRAFT 运行删除仅限发起人且 run 无关联 Issue；存在 Issue 关联的 run 一律不可删除（保护 AC6.5.1 双向链接）；导出报告（FR6.6.1）仅针对单个 run，不含跨 run 的 diff-of-diff 内容。
